# 群操作 API

本分类包含 10 个群操作 API，涵盖禁言、踢出、管理、头衔等功能。

## API 列表

| action | 说明 | 来源 | NapCat | SnowLuma |
|---|---|---|---|---|
| [`set_group_kick`](./set-group-kick) | 群组踢人 | OB11 | ✓ | ✓ |
| [`set_group_ban`](./set-group-ban) | 群组单人禁言 | OB11 | ✓ | ✓ |
| [`set_group_anonymous_ban`](./set-group-anonymous-ban) | 群组匿名用户禁言 | OB11 | ✓ | ✓ |
| [`set_group_whole_ban`](./set-group-whole-ban) | 群组全员禁言 | OB11 | ✓ | ✓ |
| [`set_group_admin`](./set-group-admin) | 群组设置管理员 | OB11 | ✓ | ✓ |
| [`set_group_anonymous`](./set-group-anonymous) | 群组匿名 | OB11 | ✓ | ✓ |
| [`set_group_card`](./set-group-card) | 设置群名片 | OB11 | ✓ | ✓ |
| [`set_group_name`](./set-group-name) | 设置群名 | OB11 | ✓ | ✓ |
| [`set_group_leave`](./set-group-leave) | 退出群组 | OB11 | ✓ | ✓ |
| [`set_group_special_title`](./set-group-special-title) | 设置群组专属头衔 | OB11 | ✓ | ✓ |
