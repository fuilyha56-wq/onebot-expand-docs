# 在线状态 API

本分类包含 4 个在线状态 API，涵盖在线状态/DIY状态/输入状态等功能。

## API 列表

| action | 说明 | 来源 | NapCat | SnowLuma |
|---|---|---|---|---|
| [`set_online_status`](./set-online-status) | 设置在线状态 | Expand | ✓ | ✓ |
| [`set_diy_online_status`](./set-diy-online-status) | 设置DIY在线状态 | Expand | ✓ | ✓ |
| [`set_input_status`](./set-input-status) | 设置输入状态 | Expand | ✓ | ✓ |
| [`nc_get_user_status`](./nc-get-user-status) | 获取陌生人在线状态 | Expand | ✓ | ✓ |
