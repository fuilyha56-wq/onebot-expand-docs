# API 总览

OneBot Expand 插件共封装 **185 个 API**（含 13 个别名），按 21 个功能域分类。每个 API 同时标记在 OneBot v11 / NapCat / SnowLuma 三方的兼容性。

## 功能域导航

| 功能域 | API 数 | 说明 |
|---|---|---|
| [消息](./message/) | 20 | 群/私聊消息发送、转发、撤回、已读标记 |
| [群操作](./group/) | 10 | 禁言、踢出、管理、头衔等 |
| [文件操作](./file/) | 16 | 群/私聊文件上传、图片/语音获取、在线文件、流式传输 |
| [账号信息](./account/) | 10 | 登录号、好友、群列表与详情查询 |
| [NapCat 扩展](./napcat-ext/) | 15 | Cookies、CSRF、状态、精华消息等 |
| [群文件管理](./group-file/) | 12 | 群文件 CRUD、文件夹、转存 |
| [群公告](./group-notice/) | 3 | 群公告发布/查询/删除 |
| [群管理扩展](./group-ext/) | 12 | 群头像/备注/加群选项/签到/打卡列表 |
| [请求处理](./request/) | 5 | 好友/加群请求处理 |
| [用户信息扩展](./user-ext/) | 9 | 好友备注/分类/单向好友/资料/头像 |
| [在线状态](./status/) | 4 | 在线状态/DIY状态/输入状态 |
| [戳一拍](./poke/) | 2 | 好友/群戳一拍 |
| [表情/收藏扩展](./emoji-ext/) | 10 | 收藏表情CRUD/详情/备注/移动/回应 |
| [AI 语音](./ai-voice/) | 3 | AI角色/语音生成 |
| [凭证/安全/下载](./cred/) | 8 | clientkey/credentials/rkey/URL安全/OCR/下载/解密 |
| [机型/其他](./misc/) | 12 | 机型/退出/包状态/内联键盘/小程序/翻译/收藏/SSO包/快速操作/分词 |
| [闪传](./flash/) | 11 | 闪传任务/消息/文件列表/URL/分享/下载/文件集CRUD |
| [群相册](./group-album/) | 7 | 群相册列表/上传/评论/点赞/删除 |
| [群待办](./group-todo/) | 3 | 群待办设置/完成/取消 |
| [QQ 空间](./qzone/) | 9 | 说说列表/动态/发表/删除/点赞/评论/拉黑/权限 |
| [Ark 分享](./ark/) | 4 | 用户/群Ark卡片分享 |

## 三方兼容性统计

| 协议端 | 支持 API 数 | 兼容率 |
|---|---|---|
| OneBot v11 标准 | 26 | 14% |
| NapCat | 167 | 90% |
| SnowLuma | 169 | 91% |

::: tip 说明
- **OneBot v11 标准**：仅统计 26 个公开 API，其余为各协议端扩展
- **NapCat**：支持插件 185 个 API 中的 167 个，其余 18 个为 SnowLuma 独有或插件扩展
- **SnowLuma**：支持插件 185 个 API 中的 169 个，其余 16 个为 NapCat 专属
:::

完整的 action × 三方兼容性矩阵见 [兼容性矩阵](../reference/compatibility-matrix)。
