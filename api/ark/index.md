# Ark 分享 API

本分类包含 4 个 Ark 分享 API，涵盖用户/群Ark卡片分享功能。

## API 列表

| action | 说明 | 来源 | NapCat | SnowLuma |
|---|---|---|---|---|
| [`share_peer`](./share-peer) | 推荐联系人/群聊卡片 | Expand | ✓ | ✓ |
| [`send_ark_share`](./send-ark-share) | 发送Ark分享 | Expand | ✓ | ✓ |
| [`share_group_ex`](./share-group-ex) | 推荐群聊卡片 | Expand | ✓ | ✓ |
| [`send_group_ark_share`](./send-group-ark-share) | 群聊Ark分享 | Expand | ✓ | ✓ |
