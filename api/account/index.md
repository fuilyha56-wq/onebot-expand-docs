# 账号信息 API

本分类包含 10 个账号信息查询 API，涵盖登录号、好友、群列表与详情查询等功能。

## API 列表

| action | 说明 | 来源 | NapCat | SnowLuma |
|---|---|---|---|---|
| [`get_login_info`](./get-login-info) | 获取登录号信息 | OB11 | ✓ | ✓ |
| [`get_stranger_info`](./get-stranger-info) | 获取陌生人信息 | OB11 | ✓ | ✓ |
| [`get_friend_list`](./get-friend-list) | 获取好友列表 | OB11 | ✓ | ✓ |
| [`get_group_list`](./get-group-list) | 获取群列表 | OB11 | ✓ | ✓ |
| [`get_group_member_list`](./get-group-member-list) | 获取群成员列表 | OB11 | ✓ | ✓ |
| [`get_group_member_info`](./get-group-member-info) | 获取群成员信息 | OB11 | ✓ | ✓ |
| [`get_group_info`](./get-group-info) | 获取群信息 | OB11 | ✓ | ✓ |
| [`get_group_detail_info`](./get-group-detail-info) | 获取群详情信息 | NapCat | ✓ | ✓ |
| [`get_group_honor_info`](./get-group-honor-info) | 获取群荣誉信息 | OB11 | ✓ | ✓ |
| [`get_robot_uin_range`](./get-robot-uin-range) | 获取机器人QQ号区间 | Expand | ✓ | ✗ |
