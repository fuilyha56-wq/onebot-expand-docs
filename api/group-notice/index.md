# 群公告 API

本分类包含 3 个群公告 API，涵盖群公告发布/查询/删除功能。

## API 列表

| action | 说明 | 来源 | NapCat | SnowLuma |
|---|---|---|---|---|
| [`_send_group_notice`](./send-group-notice) | 发送群公告 | Expand | ✓ | ✓ |
| [`_get_group_notice`](./get-group-notice) | 获取群公告 | Expand | ✓ | ✓ |
| [`_del_group_notice`](./del-group-notice) | 删除群公告 | Expand | ✓ | ✓ |
