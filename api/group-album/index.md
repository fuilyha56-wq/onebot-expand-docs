# 群相册 API

本分类包含 7 个群相册 API，涵盖群相册列表/上传/评论/点赞/删除等功能。

## API 列表

| action | 说明 | 来源 | NapCat | SnowLuma |
|---|---|---|---|---|
| [`get_qun_album_list`](./get-qun-album-list) | 获取群相册列表 | Expand | ✓ | ✓ |
| [`upload_image_to_qun_album`](./upload-image-to-qun-album) | 上传图片到群相册 | Expand | ✓ | ✓ |
| [`get_group_album_media_list`](./get-group-album-media-list) | 获取群相册媒体列表 | Expand | ✓ | ✓ |
| [`do_group_album_comment`](./do-group-album-comment) | 群相册评论 | Expand | ✓ | ✓ |
| [`set_group_album_media_like`](./set-group-album-media-like) | 群相册点赞 | Expand | ✓ | ✓ |
| [`cancel_group_album_media_like`](./cancel-group-album-media-like) | 取消群相册点赞 | Expand | ✓ | ✓ |
| [`del_group_album_media`](./del-group-album-media) | 删除群相册媒体 | Expand | ✓ | ✓ |
