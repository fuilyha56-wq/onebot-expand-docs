# 凭证/安全/下载 API

本分类包含 8 个凭证/安全/下载 API，涵盖 clientkey/credentials/rkey/URL安全/OCR/下载/解密等功能。

## API 列表

| action | 说明 | 来源 | NapCat | SnowLuma |
|---|---|---|---|---|
| [`get_clientkey`](./get-clientkey) | 获取 clientkey | Expand | ✓ | ✓ |
| [`get_credentials`](./get-credentials) | 获取 QQ 接口凭证 | Expand | ✓ | ✓ |
| [`get_rkey`](./get-rkey) | 获取 Rkey | Expand | ✓ | ✗ |
| [`get_rkey_server`](./get-rkey-server) | 获取 Rkey 服务器 | Expand | ✓ | ✓ |
| [`check_url_safely`](./check-url-safely) | 检查链接安全性 | Expand | ✓ | ✓ |
| [`ocr_image`](./ocr-image) | 图片 OCR | go-cqhttp | ✓ | ✗ |
| [`download_file`](./download-file) | 下载文件到缓存目录 | Expand | ✓ | ✓ |
| [`request_decrypt_key`](./request-decrypt-key) | 请求解密密钥 | Expand | ✗ | ✓ |
