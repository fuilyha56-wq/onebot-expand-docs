# AI 语音 API

本分类包含 3 个 AI 语音 API，涵盖 AI角色/语音生成功能。

## API 列表

| action | 说明 | 来源 | NapCat | SnowLuma |
|---|---|---|---|---|
| [`get_ai_characters`](./get-ai-characters) | 获取AI语音角色列表 | Expand | ✓ | ✓ |
| [`get_ai_record`](./get-ai-record) | AI文字转语音 | Expand | ✓ | ✓ |
| [`send_group_ai_record`](./send-group-ai-record) | 群聊发送AI语音 | Expand | ✓ | ✓ |
