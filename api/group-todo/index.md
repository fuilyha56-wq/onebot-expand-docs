# 群待办 API

本分类包含 3 个群待办 API，涵盖群待办设置/完成/取消功能。

## API 列表

| action | 说明 | 来源 | NapCat | SnowLuma |
|---|---|---|---|---|
| [`set_group_todo`](./set-group-todo) | 设置群待办 | Expand | ✓ | ✓ |
| [`complete_group_todo`](./complete-group-todo) | 完成群待办 | Expand | ✓ | ✓ |
| [`cancel_group_todo`](./cancel-group-todo) | 取消群待办 | Expand | ✓ | ✓ |
